# Native COSMIC host boundary

Date: 2026-08-12

The project laptop was inspected read-only after the QEMU proof. Its active
Wayland session is Ubuntu GNOME. The installed Wayland-session entries contain
Ubuntu/GNOME sessions but no COSMIC session, and `cosmic-session`, `cosmic-comp`,
and `cosmic-settings` are not installed.

No reboot or host modification was attempted. Native COSMIC compositor,
Settings-panel, and physical-hardware claims therefore remain outside the
current evidence; QEMU is the authoritative runtime environment.
